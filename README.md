## Trabalho de programação paralela com OpenMP

O repositório trata-se de uma implementação do método iterativo de Jacobi para solução de sistemas lineares, de forma sequencial e paralela utilização OpenMP

## Autores 
 - Ana Laura Rizzo
 - Gislayne Garabini Damasceno

## Implementação

Foi desenvolvido uma versão sequencial e paralela na linguagem C para o problema.

O sistema linear foi representado por uma matriz quadrada A, um vetor de termos
independentes b e os vetores auxiliares *x_old*, *x_new* que são responsáveis por armazenar
os valores da iteração anterior e da iteração atual, respectivamente.
